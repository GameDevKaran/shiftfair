ShiftFair: follow one decision.

A reference map of the implemented app. Prepared by the coding agent; reading this page does not establish completed learner review or learning.

Editable inputs→Worker search→Independent validation→Reviewed output

1. Change or lock an assignment

src/app.ts: invalidate stops the old worker and clears the previous result. generate validates a structured copy of the current plan before starting a new worker.

Why clear the old result?

A schedule valid for yesterday's availability may be invalid after one checkbox changes. Export stays disabled until a new result is verified. A lock is an input constraint, not a suggestion to the optimizer.

2. Separate a proof from a search limit

src/solver.ts: directConflicts catches facts such as unavailable locked people. solve enumerates combinations within a budget. validateSchedule independently checks returned assignments.

One useful investigation

Compare the zero-budget tests with the overlapping-shift bottleneck in tests/domain.test.ts. The former returns incomplete; exhaustive enumeration proves the latter impossible. Both may have no candidate, but they support different claims. The independent oracle also enumerates overstaffed possibilities to check the restricted search's optimum.

3. Export what was actually reviewed

src/export.ts: scheduleRows rejects invalid assignments before generating CSV or print rows. Scores are recalculated. src/storage.ts saves inputs only, so old result flags cannot become trusted evidence after reload.

Try the complete path

Generate the synthetic sample, lock an assignment, then mark that person unavailable for that shift. Observe the named conflict and disabled export. Restore availability, regenerate and compare the locked row in the screen and CSV. Record what you actually observe; do not infer a pass from this description.

Reusable practice: keep the input contract, search outcome and independently checked result distinct. A time limit is evidence about the search, not evidence that the requested schedule is impossible.
